# Tài liệu dự án website Cocoon

Đây là điểm vào chính cho tài liệu nội bộ. Đọc theo thứ tự sau nếu bạn mới mở repo lần đầu:

1. **[Tổng quan dự án](./project-overview.md)** — Dự án là gì, trang nào là “sản phẩm”, song ngữ, thương hiệu.
2. **[Cấu trúc repo](./repo-structure.md)** — File và thư mục quan trọng, luồng chỉnh sửa nội dung/UI.

Trang web **chạy tĩnh**: mở `index.html` hoặc `en.html` qua HTTP server bất kỳ (không bắt buộc build step cho site chính).
